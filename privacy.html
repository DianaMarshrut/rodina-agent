Privacy Policy

Effective date: October 23, 2026

Who we are

Rodina Agent ("the app") is a private assistant operated by Anna Rodina for her own use. Contact: anhen1986@gmail.com.

What data the app accesses

With the account owner's consent, the app accesses Google Drive, Google Sheets and Google Docs data of the connected Google account through Google APIs: file names, folders, file contents, spreadsheet and document data.

How the data is used

The data is used only to perform tasks the owner requests: searching, reading, creating and editing her files. It is not used for advertising, profiling or any other purpose.

Sharing

Google user data is not sold, rented or transferred to third parties, except as required to perform the owner's requested tasks or by law. Humans do not read the data except with the owner's explicit permission, for security purposes, or as required by law.

Storage and security

Access tokens are stored on a private server with restricted access. File contents are processed only for the duration of a task and are not kept in separate databases.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. On request to the contact email, stored tokens are deleted.

Кратко по-русски

Приложение с согласия владельца аккаунта получает доступ к Google Диску, Таблицам и Документам только для выполнения её задач. Данные не продаются и не передаются третьим лицам. Отозвать доступ можно на myaccount.google.com/permissions. Контакт: anhen1986@gmail.com.
